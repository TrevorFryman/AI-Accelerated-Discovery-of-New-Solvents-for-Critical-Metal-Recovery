# GSK Solvent G-Score Prediction — Implementation Plan

## Overview

Build a reproducible cheminformatics ML project that trains three XGBoost regression models
(Morgan Fingerprints, RDKit Descriptors, ChemBERTa Embeddings) on the GSK Solvent
Sustainability dataset to predict greenness scores (G-scores). Phase 1 covers project
scaffolding + EDA; Phase 2 covers descriptor generation; Phase 3 covers model training
and evaluation.

---

## Dataset Summary (154 solvents)

| Field | Detail |
|---|---|
| Target | `G-score` (continuous, ~3.0–8.76) |
| Key input | `solvent_SMILES` |
| Classes | Water/acids, Alcohols, Esters, Carbonates, Ketones, Aromatics, Hydrocarbons, Ethers, Dipolar Aprotics, Halogenated, Other |
| Known issues | `¬†` UTF-8 artifacts in some IUPAC names, duplicate SMILES (IMS ethanol ≡ ethanol; petroleum spirit ≡ 2-methylpentane), Trifluorotoluene SMILES appears incorrect |
